# Breathe - The Finance Academy
Breathe is a web application that helps young adults navigate the complexities of personal finance. In all honesty, the idea of this application is based on my own previous hardships of trying to understand money as a young 20-something. With so many resources available and just as many contradicting opinions online, I wished for one singular resource that only taught me what I needed to know in a simple manner without the extra bias. After speaking to my peers, this type of resource would have been a dream to them as well. This is where Breathe comes in! This application allows users to learn the basics of what they need to know on certain financial topics and supplies them with the confidence to make meaningful choices for themselves. 

This resource isn’t meant to make anyone rich, just to make money less complicated.

To get started, click on the link below and select a lesson topic you'd like to learn about!
